# Skedra Project Documentation

Copy these files into the root of the Skedra repository.

- `context.md` — product vision, specification, confirmed decisions, architecture direction, and implementation guidance.
- `PRD.md` — product requirements and user experience specification.
- `AGENTS.md` — canonical coding-agent instructions.
- `agent.md` — lightweight entry point for workflows looking for a lowercase filename.
- `docs/design-references/Nixtio.jpg` — user-provided visual design reference.

Read `context.md`, then `AGENTS.md`, and consult `PRD.md` for product experience and UI requirements. Check the actual repository before assuming any documented feature exists.
